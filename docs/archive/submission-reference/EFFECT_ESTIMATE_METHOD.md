# 자동화 전후 효과 추정의 계산 근거

이 자료는 실제 사용자 PC 자동검사 시간에 설명용 가정을 결합한 추정입니다. 수동 검토시간·AI 사용 후 사람의 추가 작업시간을 실측한 비교실험이 아닙니다.

## 실측값

- 자동검사 처리시간: 434.06초, 약 7분 14초.
- 같은 시연의 입력: DOCX 1개·XLSX 1개, REQ-001 / REQ-006 / REQ-018.
- 완료 화면·결과·Word 보고서를 대조한 단일 사례입니다. 원자료는 supporting_demo/demo_observations.json과 evidence/에 있습니다.
- 자동검사 처리시간은 사람의 파일 등록·후보 검토·보고서 저장까지의 전체 업무시간이 아닙니다.

## 설명용 가정

| 가정 항목 | 값 |
|---|---:|
| 사용 전: 직접 검토·근거 정리·보고서 작성 전체 | 30분 |
| 사용 후: 프로젝트 입력·문서 등록 | 1분 |

30분·1분·8분·1분은 이번 추정을 위한 예시 조건입니다. 측정한 시간이나 사용자의 경험값, 업계 평균 또는 보수적으로 검증된 기준이 아닙니다. 사용자는 이 조건을 실제 관찰값이 아닌 가정으로 표시한 자료의 추가를 승인했습니다.

비교 범위는 동일한 두 문서와 같은 세 규칙의 점검·근거 정리·보고서 완성까지라는 시나리오로 설정했습니다. 실제 두 방식의 작업 품질이 동등한지는 검증하지 않았습니다.

## 계산

- 사용 후 추가 작업 가정 = 60 + 480 + 60 = 600초.
- 사용 후 전체 추정 = 434.06 + 600 = 1,034.06초, 약 17분 14초.
- 예상 절감시간 = 1,800 − 1,034.06 = 765.94초, 약 12분 46초.
- 예상 절감률 = 765.94 / 1,800 × 100 = 약 42.6%.

| 수동 전체시간 가정 | 사용 후 전체 추정 | 예상 차이 |
|---|---|---|
| 15분 | 17분 14초 | 약 2분 14초 증가 · −14.9% |
| 30분 | 17분 14초 | 약 12분 46초 감소 · 42.6% |
| 60분 | 17분 14초 | 약 42분 46초 감소 · 71.3% |

위 가정에서 수동 전체시간이 약 17분 14초보다 길어야 시간 감소가 예상됩니다. 추가 검토시간이 길어져도 예상 효과는 줄어듭니다. Excel의 노란 가정 칸을 바꾸면 계산이 달라집니다.
