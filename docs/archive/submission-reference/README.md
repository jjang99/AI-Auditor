# 이전 제출 참고자료 보관

현재 제출 기준은 보고서 작성시간 비교 PDF, 소스 ZIP, 프로젝트 설명 MD입니다. 이 폴더는 이전 추정·기능검증·기술 테스트 기록을 원문 그대로 보관합니다. 현재 효과측정지표 대신 제출하는 자료가 아닙니다.

| 자료 | 해석 |
|---|---|
| AI_Auditor_Effect_Estimate_1page.pdf / .docx / AI_Auditor_Effect_Estimate.xlsx | 수동 30분·추가 작업 10분을 가정한 과거 시나리오. 실제 달성한 절감률이 아님 |
| EFFECT_ESTIMATE_METHOD.md / estimate_assumptions.json | 위 가정과 계산 근거 |
| AI_Auditor_Effect_Measurement_1page.pdf / .docx / AI_Auditor_Measurement_Data.xlsx | 단일 합성 문서의 결함 검출 기능검증. 전체 업무 시간절감이나 평균 정확도가 아님 |
| MEASUREMENT_METHOD.md | 합성 문서 검증 조건과 한계 |
| technical_validation.json / .xml | 과거 코드 기준의 테스트 기록. 현재 보안 보완본 테스트는 submission/security_validation/에 있음 |

11개 원본의 바이트와 파일명은 보존했습니다. 원문 안의 experiment/, supporting_demo/ 등의 경로는 작성 당시 submission/을 기준으로 합니다. 해당 근거 폴더는 현재도 submission/에 보관합니다. 현재 효과측정 원자료와 보안 보완 기록은 submission/의 안내를 참고하세요.

이전 자료는 소스 ZIP의 같은 경로에 포함되고, 남은 제출자료 묶음 ZIP의 docs/archive/submission-reference/에도 포함됩니다.
