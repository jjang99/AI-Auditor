# 감리결과서 기반 105개 Rule 실무 검증·매핑 기준

## 1. 분석 기준
- 원본: 감리 관련 파일 114개 (Project 기존 UI 참고파일 제외)
- 형식: PDF 94 / DOCX 19 / XLSX 1
- 독립 보고서 연도: 2019~2025 (2025 보고서 일부에 2026 후속 일정 포함)
- SHA-256 완전 동일본 3쌍은 빈도 중복에서 제외. 초안/수정본, PDF/DOCX, 전문별첨은 내용 차이를 위해 유지.
- 3회 교차검증: 요약 지적표 → 상세 본문 → 전문분야/별첨(FP, AI/RAG, 보안, 데이터, UI/UX).
- 키워드 유사성만으로 기존 Rule에 억지 매핑하지 않으며, 직접 사례가 없으면 `미확인`으로 유지한다.

## 7. 재사용 원칙
- 향후 85개 구현은 P1 → P2 → P3 → P4 순서를 기본으로 하되 개발 난이도·의존성을 함께 고려한다.
- 신규 후보는 승인 전까지 Catalog에 반영하지 않는다.
- 새 감리결과서는 기존 분석에 증분 반영한다.
- 상세 근거와 대표 출처는 분석 산출물 `final_105_mapping_v2.csv`, `new_rule_candidates_v2.csv`에 보존한다.
- 코드/UI는 본 분석 단계에서 변경하지 않는다.
