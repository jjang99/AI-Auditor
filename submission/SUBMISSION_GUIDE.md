### 현재 자료가 입증하는 범위

이 자료는 실제 자동화 수행 결과의 정량 요약입니다.
수동 소요시간이 측정되지 않아 **전후 시간절감률, 오류율 감소, 인건비 절감액을 입증한 비교실험은 아닙니다.**
Issue 후보 7건을 ‘오류를 7건 정확히 찾아냈다’거나 ‘오탐률 0%’라고 바꾸어 표현하지 않습니다.
434.06초는 자동검사 구간이고, 입력·사람 검토·보고서 저장까지의 전체 시간은 아닙니다.

제출처가 전후 절감률을 반드시 요구한다면 추가 비교측정을 해야 합니다.
이때 `AI_Auditor_Measurement_Worksheet.xlsx`에 실제 값을 넣으면 계산됩니다.

## 3. 추가 비교측정 방법(녹화 불필요)

1. 같은 수준의 문서와 같은 점검 범위, 같은 결과 정리 기준을 정합니다.
2. 수동 검토 1회: 문서 열기부터 문제 확인·근거 정리·보고서 완성까지 전체 시간을 초로 잽니다.
3. AI 활용 검토 1회: 파일 등록부터 AI 대기·사람의 결과 확인·보고서 저장까지 전체 시간을 초로 잽니다.
4. 기록지의 노란 칸에 실제 ‘수동 전체 작업시간’과 ‘AI 활용 전체 작업시간’을 입력합니다.
5. 시간절감률 = (수동 전체시간 − AI 활용 전체시간) ÷ 수동 전체시간 × 100.

이미 정답을 아는 문서로 반복하면 학습효과가 생길 수 있습니다.
조건을 기록하고, 가능하면 독립 검토 또는 동등 난이도의 새 자료를 사용하세요.
단일 참여자·단일 사례 결과는 그렇게 표시하고 전체 프로젝트의 평균 성과로 일반화하지 않습니다.
AI가 더 오래 걸렸다면 음수 결과를 그대로 기록합니다.

기존 시연의 434.06초를 ‘AI 활용 전체 작업시간’ 칸에 자동으로 넣지 않았습니다.
정확도 지표는 독립적으로 확정한 정답표와 정탐/오탐/미탐 개수로 확인한 뒤 계산합니다.
