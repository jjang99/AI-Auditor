# 요약표 작성시간 비교의 범위와 출처

## 사용자 제공값

기록일 2026-10-25. 사용자가 같은 프로젝트의 기존 검사결과를 대상으로 요약표 작성·저장·열기·확인 시간을 수동 약 7분 22초, 자동 약 6초로 정정하여 제공했습니다. 이후 대략값이며 수동 시간이 더 길어질 수도 있다고 설명했습니다. 이 자료는 **사용자 보고에 따른 단일 사례 근사 비교**로 표시합니다. 타이머·영상·완성 문서 파일은 받지 않아 독립 재검증하지 않았습니다.

## 공통 완료 기준

시연에 사용한 두 문서의 검사결과가 이미 있는 상태에서 요약정보를 Word 문서로 작성하고 저장한 뒤 열어 확인하는 단계입니다. 원문 문서 검토·AI 검사·개별 이슈 판단이나 준비시간은 포함하지 않습니다.

공통 요약 8항목: 프로젝트명 / 부서명(기관명) / 프로젝트 구분 / 검사일시 / 검사유형 / Score·Grade / 적용 규칙 수 / 전체 이슈 수.

| 구분 | 시작 | 종료 |
|---|---|---|
| 수동 | 빈 Word 문서에서 2열·8행 요약표 작성 시작 | 저장 문서를 다시 열어 8개 항목 확인 완료 |
| 자동 | 같은 프로젝트 결과 화면에서 Export Report 클릭 직전 | DOCX 저장·열기 후 동일 8개 항목 확인 완료 |

앱·빈 Word 문서·저장 폴더 등은 미리 준비하도록 안내했습니다. 자동 보고서에는 이슈 상세도 포함되지만 비교의 공통 완료 기준은 요약 8개 항목입니다. 두 결과물의 실제 내용을 받아 대조한 검증은 아닙니다.

## 계산

- 수동 보고시간: 7 × 60 + 22 = 442초.
- 자동 보고시간: 6초.
- 차이: 442 − 6 = 약 436초 = 약 7분 16초.
- 제공시간의 단순 환산 감소율: (442 − 6) / 442 × 100 ≈ 98.6%.

약 98.6%는 이 문서화 단계의 보고시간으로 계산한 값이며 프로그램 전체 검사·감리 업무의 절감률이 아닙니다. 알려준 수동 시간이 늘어날 수 있다는 이유로 더 큰 값을 임의로 추가하거나 ‘최소·평균·보수적 실측’이라고 표시하지 않았습니다.

## 정정과 한계

초기 수동 3분 41초·자동 1초는 이 계산에 사용하지 않았습니다. 사용자가 자동 1초는 내보내기까지만의 시간이라고 설명하고 저장·열기·확인을 포함한 최종 두 시간을 정정했습니다. 원자료 JSON에 이 정정 맥락을 기록했습니다.

동일인이 수동→자동 순서로 각 1회 수행한 사례입니다. 반복·교차 측정, 평균값, 신뢰구간이 아닙니다. 순서·학습·익숙함이 영향을 줄 수 있으며 작업량·숙련도에 따라 시간은 달라집니다. 정확도·오류율·인건비 절감은 측정하지 않았습니다.

report_time_observations.json은 사용자 제공값과 출처·범위·정정을, AI_Auditor_Report_Time_Data.xlsx는 계산식을 담습니다. 이전 가정 시나리오(42.6%)와 합성 결함 검출 실험(75%)은 별도 참고자료로 보존하며 이 비교에 혼합하지 않습니다.
